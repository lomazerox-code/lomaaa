=== المعتمد جروب — النسخة النهائية (تحديث إصلاح الـ Refresh + توافق Google Ads) ===

المشكلة التي تم حلها:
- كانت صفحات مثل /brands/ و /services/ و صفحات المحافظات ملفات HTML ثابتة
  منفصلة لا تُحمّل تطبيق React إطلاقاً. لذلك عند عمل Refresh على أي صفحة كانت
  تظهر نسخة قديمة بشكل مختلف وغير مرتب.

ما تم عمله:
1. تحويل كل صفحة (الماركات، الخدمات، الأعطال، من نحن، اتصل بنا، الشروط،
   سياسة الخصوصية، و27 محافظة) إلى نقطة دخول لتطبيق React نفسه.
   => الآن عند الـ Refresh تظهر نفس الصفحة تماماً بنفس الشكل.
2. الاحتفاظ بالمحتوى النصي داخل <noscript> لمحركات البحث ومراجعة Google.
3. إضافة ملف .htaccess كامل لاستضافة Hostinger (Apache):
   - توجيه HTTPS وإزالة www.
   - إصلاح رابط /privacy-policy/ ليحوّل إلى /privacy/.
   - قاعدة SPA fallback (أهم إصلاح للـ Refresh).
   - ترويسات أمان + ضغط + Caching + أنواع ملفات JS الصحيحة.
4. توافق Google Ads:
   - إزالة كود AdSense التجريبي المكسور (client=ca-pub-XXXX) من الصفحة الرئيسية.
   - تنظيف ملف ads.txt.
   - تحديث sitemap.xml (privacy-policy -> privacy).

طريقة الرفع على Hostinger:
- ارفع محتويات هذا المجلد بالكامل داخل public_html.
- تأكد أن ملف .htaccess (ملف مخفي يبدأ بنقطة) تم رفعه أيضاً.
  في File Manager فعّل "Show Hidden Files (dotfiles)" قبل الرفع.
- بعد الرفع افتح أي صفحة واعمل Refresh للتأكد.

ملاحظة: إذا أردت لاحقاً تفعيل إعلانات AdSense، ضع رقم الناشر في ads.txt.
